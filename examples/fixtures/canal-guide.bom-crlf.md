# 星見町の水路管理の手引き

この文書は試験用の合成資料です。実在の地名・組織・人物とは関係ありません。

## 1. 概要

星見町の水路は、春の取水期と秋の排水期で見回りの回数を変えます。詳しい台帳は [水路台帳](./registry.md) を、
外部の参考例は [参考ページ](https://example.com/guide?lang=ja&topic=canal#top) を見てください。

> 点検記録は、現場で書いた内容をそのまま残します。後から言い換えないでください。

## 2. 点検の手順

1. 取水口の周りのごみを集める。
2. 水位の目盛りを読み、記録表に書く。
3. 異常があれば「要確認」と書き、写真の番号を添える。

- 班の合言葉: 👨‍👩‍👧‍👦（家族みんなで声をかける）
- 旗の確認: 🇯🇵
- 結合文字の例: がé（分解形）と ｶﾞ（半角カナ）

## 3. 記録表

| 地点 | 水位(cm) | 状態 | 備考 |
| --- | ---: | --- | --- |
| 一の堰 | 42 | 良好 | 異常なし |
| 二の堰 | 37 | 要確認 | 枝が詰まっている |
| 三の堰 | 51 | 良好 | 先週より増水 |

## 4. 集計の例

水位の平均を求める簡単な手順です。

```ts
// 水位の平均（合成データ）
const levels = [42, 37, 51];
const mean = levels.reduce((a, b) => a + b, 0) / levels.length;
console.log(`平均水位: ${mean.toFixed(1)} cm`);
```

インラインの記法 `mean` も使います。コードブロックの中の `# 見出しに見える行` は見出しではありません。

## 5. 注意

- 雨の日は無理に近づかない。
- 夜間は二人以上で行う。
- 記録表の「備考」は空欄にしない。

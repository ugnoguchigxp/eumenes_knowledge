# 発注連携 API メモ

仕入れ先の注文画面とつなぐための API のメモ（英数字混在の例）。

## エンドポイント

| メソッド | パス | 用途 |
| --- | --- | --- |
| POST | /v2/orders | 注文の作成 |
| GET | /v2/orders/{id} | 注文の状態の確認 |
| DELETE | /v2/orders/{id} | 注文の取消し |

## 仕様の要点

- 認証は Bearer トークン。トークンの有効期間は 24 時間。
- リクエストの本文は JSON で、`item_code` と `quantity` を必ず含める。
- タイムアウトは 30 s。再送するときは、同じ `Idempotency-Key` を使う。
- 取消しは、納品日の前日 12:00 まで。

```json
{ "item_code": "FLR-25", "quantity": 12, "deliver_on": "2026-11-10" }
```

## 既知の問題

`quantity` に小数を入れると 422 が返る。袋単位で整数にして送る。

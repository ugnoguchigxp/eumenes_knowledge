# 料理メモ

家で作る料理のコツ。

## だしのとり方

1. 昆布を 水 1 L に入れて、30 分置く。
2. 弱火にかけ、沸騰する直前に昆布を取り出す。
3. 火を止めて鰹節を入れ、2 分待って漉す。

## 味噌汁

- 味噌は沸騰させない。火を止めてから溶く。
- 具は、根菜を先に煮て、葉物は最後に入れる。
- 豆腐を入れるときは、煮立たせず温める程度にする。

## 煮物の味付け

| 材料 | 分量の目安 |
| --- | --- |
| 醤油 | 大さじ 2 |
| みりん | 大さじ 2 |
| 砂糖 | 小さじ 1 |
| だし | 200 ml |

煮物は、一度冷ますと味がしみる。大根は下ゆでしてから煮る。
作り置きは冷蔵庫で 3 日以内に食べ切る。

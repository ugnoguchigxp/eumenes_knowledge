# 蔵書整理の手引き

架空の「ひだまり図書館」で、年に一度行う蔵書の点検と整理の手引き。

## 準備

- 点検期間中は、貸出を 1 週間止める。利用者には掲示で知らせる。
- 配架の棚番号と蔵書台帳を照らし合わせる印刷物を用意する。

## 分類番号

| 分類 | 内容 |
| --- | --- |
| 913 | 日本の小説 |
| 290 | 地理・旅行 |
| 596 | 料理・食品 |
| 726 | 絵本・漫画 |

## 除籍の基準

1. 破損がひどく、修理しても使えない本。
2. 内容が古くなった実用書。ただし郷土資料は除く。
3. 同じ本が 3 冊以上あり、貸出が少ないもの。

除籍する本は、リサイクル市で配る。台帳には除籍の日付と理由を書き込む。
作業は司書の長谷部が取りまとめ、ボランティアが書架を手伝う。

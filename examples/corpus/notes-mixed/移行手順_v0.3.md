# ひきだし → Lantern 移行手順 v0.3

作成: 大野健太　更新: 2026-10-14

## 前提

- 移行元: ひきだし（Hikidashi 4.2）。ＤＢはＭｙＳＱＬ 5.7
- 移行先: Lantern。検索サーバ 1 台（Northwind Cloud の VM、16GB）
- 作業は三ツ森製作所 情報システム課の 2 名で行う

## 手順

1. ひきだしを読み取り専用にする（管理画面 → 設定 → 書き込みを止める）
2. hikidashi-sync を手動で 1 回動かす
   `bun run sync --full --since 2019-01-01`
3. 件数を確かめる。ひきだし側と Lantern 側で、ページ数が合うこと
4. 全文検索で「品質保証部」「浜松工場」を引いて、上位に出ることを確かめる
5. 問題なければ、夜間バッチを有効にする

# 正規化キーとモデルの判断が食い違う組

キーは `nfkc`（kg.md §8）。抽出は `verification/kg-ai-memory/20261109-names-charclass/knowledge.db` のもの。比べた実行ごとに、キーが同じかどうかと、その実行のモデルの判断が食い違った組を、キーの組ごとに 1 組ずつ、決まった擬似乱数の順で並べる。

- 並ぶのはモデルが判断した組だけ。v3 はまとまりごとに 1 件しか問わないので、キーが同じでもモデルが判断していない組は多い。`unsure` の組は並べない。
- 同じキーの組に食い違いが何組あっても、並ぶのは 1 組。数は表の全体の数と比べて読む。
- 「判定」は空（`--judgments` で埋める）。
